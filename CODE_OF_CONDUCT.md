# Code of Conduct

We want SwitchGPT to be a welcoming, technically careful project. Contributors must be respectful, assume good faith, explain disagreements with evidence, and avoid harassment, discrimination, doxxing, or sharing private credentials.

Project maintainers may remove comments, reject changes, or restrict participation when behavior threatens people, private data, or the safety boundaries of the project.

Report serious conduct concerns privately through the same channel described in [SECURITY.md](SECURITY.md).
