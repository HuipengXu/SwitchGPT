# Brand release review

Status: public release approved under private permission confirmed by the product owner.

This is a release-readiness review, not legal advice or a trademark clearance.
It uses OpenAI's current official materials:

- [OpenAI Design Guidelines](https://openai.com/brand/)
- [OpenAI Terms of Use](https://openai.com/policies/terms-of-use/)

## Current conflicts

OpenAI's guidelines say that the `GPT` brand may not be used in app, product,
developer, or company names. Without separate permission, the current
`SwitchGPT` product and repository name would not pass the project's public brand
gate.

The same guidelines say not to modify the OpenAI logo, incorporate it into an
independent brand, or create a similar logo. The current icon was deliberately
developed from the Blossom's interwoven visual language and would ordinarily be
blocked by this review.

The product owner confirmed on 2026-08-18 that OpenAI granted private permission
covering the current `SwitchGPT` name and icon. The private correspondence and
any identifying details are not stored in this repository. This resolves the
project's brand publication gate for this release only; it does not imply a
public endorsement or remove the requirement to keep OpenAI references
secondary and accurate.

Accurate descriptive references to ChatGPT and the official OpenAI sign-in flow
remain necessary to explain interoperability. They must stay secondary to the
independent product brand and must not imply that OpenAI created, supports,
certified, or endorsed the app.

## Release handling

For this authorized release:

1. Keep `SwitchGPT` as the product and repository name for this release.
2. Keep the current icon under the confirmed private permission; do not describe
   it as an OpenAI logo or imply public endorsement.
3. Keep all ChatGPT/OpenAI references factual, secondary, and limited to
   interoperability and the official sign-in flow.
4. Repeat the complete test, matrix, public-history, Developer ID, notarization,
   staple, Gatekeeper, and checksum checks against the exact release candidate.
5. Do not place the private authorization correspondence in the repository.

## Release identity

The public alpha uses the existing `SwitchGPT` name, bundle identifiers, helper
identifiers, website metadata, and icon. A future release may revisit the brand
independently; that is outside this publication step.
